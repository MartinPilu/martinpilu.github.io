# Proyectos

Cada subcarpeta es un proyecto independiente con su propia landing page y documentación.

- [`SACP/`](./SACP/README.md): Sistema de Administración de Consorcio de Propietarios.
- [`Radio_Jurney/`](./Radio_Jurney/README.md): Herramientas y proyectos de radioafición.

Para agregar un nuevo proyecto, crear una carpeta `projects/<NombreProyecto>/` con un `README.md` y una subcarpeta `landing/` (siguiendo la estructura de los proyectos existentes).
