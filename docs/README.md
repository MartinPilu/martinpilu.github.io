# Documentación general

Este directorio contiene la documentación transversal del repositorio (no específica de un proyecto individual).

## Contenido

- [`architecture.md`](./architecture.md): estructura del repositorio, convenciones y estrategia de despliegue.
- [`roadmap.md`](./roadmap.md): lista de proyectos planeados y su estado.

## Convención

Cada proyecto bajo `projects/` mantiene su propia documentación en su propia carpeta y todo lo necesario permitiendo la migraracion del proyecto a su porpio repositorio en cualquier momento. (`projects/<nombre>/README.md`). Este folder es solo para documentación que aplica a todo el repositorio.
